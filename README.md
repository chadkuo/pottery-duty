# 陶藝班值日生線上排班

取代 LINE 群組手動接龍：同學自己上網點日期，系統即時擋額滿、算次數，每週自動寄提醒。

**維護成本：0 元。** 用 GitHub Pages（靜態網頁）+ Google Apps Script（API）+ Google 試算表（資料庫），全部是免費額度內，沒有伺服器、沒有訂閱、沒有信用卡。

---

## 它解決了什麼

| 以前（LINE 接龍） | 現在 |
| --- | --- |
| 班長手動貼 18 行、每次有人回就要重貼一次 | 同學自己點，名單即時更新 |
| 兩個人同時回同一天 → 超過 3 人 | 額滿自動鎖住，第 4 個人點不下去 |
| 班長要人工數誰還沒排滿 2 次 | 網頁下方直接列出未達標名單 |
| 換班要在群組喊話 | 自己取消、別人補位，班長不用管 |
| 上課當天沒人記得自己是值日生 | 每週二早上 07:00 自動寄提醒信 |
| 每學期重做一次 | 改試算表的日期就好，程式不用動 |

## 系統長怎樣

```
同學的手機瀏覽器
        │  （點一下報名 / 取消）
        ▼
GitHub Pages  docs/index.html          ← 靜態網頁，免費、免維護
        │  fetch POST
        ▼
Google Apps Script  apps-script/Code.gs ← 當 API，免費額度綽綽有餘
        │
        ▼
Google 試算表                            ← 就是資料庫，班長隨時可手改
        │
        └─ 時間觸發器 ─► 每週二 07:00 提醒當天值日生
                        每週日 20:00 把排班進度寄給班長
```

## 安裝步驟（約 15 分鐘，只需做一次）

### 1. 建立試算表與後端

1. 開 [sheets.new](https://sheets.new) 建一份新的 Google 試算表，命名為「陶藝班值日生」。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把編輯器裡原本的 `function myFunction() {}` 全部刪掉，貼上 [`apps-script/Code.gs`](apps-script/Code.gs) 的完整內容，存檔（Ctrl/Cmd + S）。
4. 在上方的函式下拉選單選 **`setup`** → 按 **執行**。
   第一次會跳出授權畫面：選你的 Google 帳號 → 「進階」→「前往（不安全）」→ 允許。
   *（這個「不安全」提示是因為腳本沒有經過 Google 審核，是你自己寫的腳本，正常現象。）*
5. 回到試算表，會看到自動建好 4 張工作表：**設定 / 學員名單 / 排班表 / 操作紀錄**。

### 2. 填入班上資料

- **學員名單**：目前只預填了 LINE 上看得到的 8 位，請把其餘同學一列一位補上。
  `Email` 欄是選填 — 有填的人才會收到每週提醒信。
- **設定**：把「班長信箱」填成你的 email（每週進度信會寄到這裡）。其他預設值可以不動。
- **排班表**：已依截圖預填 18 堂課與現有的排班。日期或停課週有變動就直接改這裡。
  `需排值日生` 取消打勾＝那一週不用排（公民週、最後一堂已預設取消）。

### 3. 開啟自動提醒

回到 Apps Script，函式選 **`installTriggers`** → 執行。
會建立兩個排程：週二 07:00 提醒當天值日生、週日 20:00 寄進度給班長。

### 4. 部署成 API

1. Apps Script 右上角 **部署 → 新增部署作業**。
2. 齒輪圖示選 **網頁應用程式**。
3. 兩個關鍵設定 —— **一定要這樣設，否則同學會打不開**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按部署，複製那串 **網頁應用程式網址**（`https://script.google.com/macros/s/AKfy.../exec`）。

### 5. 上線網頁

1. 編輯 [`docs/config.js`](docs/config.js)，把剛剛的網址貼進去。
2. 把這個資料夾推上 GitHub（見下方指令）。
3. GitHub repo → **Settings → Pages** → Source 選 `Deploy from a branch`，
   Branch 選 `main`、資料夾選 **`/docs`** → Save。
4. 一分鐘後就會有網址：`https://<你的帳號>.github.io/pottery-duty/`
5. **把這個網址貼到 LINE 群組公告**，收工。

```bash
cd /Users/chadkuo/pottery-duty
gh repo create pottery-duty --public --source=. --remote=origin --push
```

## 日常使用

### 同學

打開網址 → 上方選自己的名字（只需選一次，瀏覽器會記住）→ 點想值日那天的「＋ 我要值日」。
想換掉就點自己的名字格子 →「取消」，別人就能補位。
頁面上方永遠顯示「下一堂課的值日生是誰」，最下方顯示自己還差幾次。

### 班長

- 排班表就是試算表，任何時候都能直接手改，網頁會即時反映。
- 試算表上方會多一個 **「值日生」選單**：
  - **產生 LINE 公告文字** — 把目前排班輸出成跟原本接龍一模一樣的格式，可直接複製貼回群組。
  - **立即寄出今日提醒** / **立即寄出進度給班長** — 不等排程，馬上手動寄一次。
- 排班全部確定後，把「設定」裡的 **開放報名** 改成 `FALSE`，網頁就變唯讀，避免有人亂動。

### 下個學期

只要改試算表：
1. **排班表** 換成新學期的 18 個日期，值日生欄位清空。
2. **設定** 的學期名稱改一下。
3. **學員名單** 更新。

程式碼完全不用動，網址也不用換。

## 設計上的取捨

**沒有登入機制。** 同學只要從下拉選單挑自己的名字就能報名 — 就跟原本 LINE 接龍一樣，
靠的是班上的互信。好處是零摩擦，年長同學也會用；代價是理論上有人可以幫別人取消。
每一筆異動都會寫進「操作紀錄」工作表，真的出事查得到，也能手動改回來。
若之後真的需要，再加密碼不難。

**提醒走 Email 而不是 LINE。**
LINE Notify 已於 2025/3/31 終止服務。改用 LINE 官方帳號（Messaging API）的話，
免費方案訊息額度很低，而且**推播到群組是按群組人數計費**，57 人 × 每週一次會直接爆掉。
所以預設走 Gmail（Apps Script 每天 100 封免費額度，我們一週用不到 5 封）。

未來若想要 LINE 通知，唯一真正免費的做法是「機器人只回覆、不主動推播」：
把 bot 加進群組，有人輸入「值日生」它才回答（reply 訊息不計免費額度）。
這可以之後再加，不影響現在的架構。
