# 陶藝班值日生線上排班

取代 LINE 群組手動接龍：同學自己上網點日期，系統即時擋額滿、算次數、處理臨時換人，每週自動寄提醒。

**維護成本：0 元。** GitHub Pages（靜態網頁）+ Google Apps Script（API）+ Google 試算表（資料庫），全部在免費額度內，沒有伺服器、沒有訂閱、沒有信用卡。

**程式碼不需要為了新學期而修改。** 堂數、上課日、成員、停課日全部放在試算表。

---

## 它解決了什麼

| 以前（LINE 接龍） | 現在 |
| --- | --- |
| 班長手動貼 18 行，每次有人回就要重貼一次 | 同學自己點，名單即時更新 |
| 兩個人同時回同一天 → 超過 3 人 | 額滿自動鎖住，第 4 個人點不下去 |
| 班長要人工數誰還沒排滿 2 次 | 網頁下方直接列出未達標名單 |
| 當天有人不能到，在群組喊到沒人回 | 按「我不能到，找人代班」，全班看到求救橫幅，誰都能一鍵接手 |
| 換人之後班長要記得改次數 | 代班成立自動轉移次數，原值日生 −1、代班人 +1 |
| 新同學要班長幫忙加進名單 | 同學可自己在網頁加入 |
| 每學期重做一次 | 改試算表三格 → 按一下重建，動手前先確認並自動備份 |
| 上課當天沒人記得自己是值日生 | 上課日早上 07:00 自動寄提醒信 |

## 系統長怎樣

```
同學的手機瀏覽器
        │  報名 / 取消 / 徵求代班 / 我來代
        ▼
GitHub Pages  docs/index.html          ← 靜態網頁，免費、免維護
        │  fetch POST
        ▼
Google Apps Script  apps-script/Code.gs ← 當 API，免費額度綽綽有餘
        │
        ▼
Google 試算表（6 張工作表）              ← 所有設定與資料，班長隨時可手改
        │
        └─ 時間觸發器 ─► 上課日 07:00   提醒當天值日生
                        前一天 20:00   把排班進度寄給班長
```

### 六張工作表

| 工作表 | 做什麼 | 誰會動它 |
| --- | --- | --- |
| **設定** | 班級名稱、第一堂課日期、總堂數、上課時間、每週人數、每人最少次數、各種開關 | 班長，每學期 |
| **學員名單** | 成員與 Email（Email 選填，有填才收得到提醒信） | 班長；同學也能從網頁自己加入 |
| **特殊安排** | 哪幾天不用排值日生（公民週、國定假日、期末聚餐…） | 班長，每學期 |
| **排班表** | 由上面三張自動產生。誰值哪一天就寫在這 | 系統自動；班長也可以直接手改，**改完立刻生效** |
| **代班需求** | 誰徵求代班、誰接手、什麼時候 | 系統自動 |
| **操作紀錄** | 每一筆異動的稽核軌跡 | 系統自動 |

## 安裝步驟（約 15 分鐘，只需做一次）

> **關於姓名：** 這個 repo 是公開的，所以裡面的示範資料、測試與一次性匯入用的都是化名
> （王小明、陳美玲…）。班上同學的真實姓名只存在**你的 Google 試算表**裡，不會出現在 GitHub 上。
>
> 本機另外有一份 `local/Code.gs`，內容跟 `apps-script/Code.gs` 完全一樣，
> 只是把示範姓名換回真實的班級名單。**要貼進 Apps Script 的是 `local/Code.gs` 那一份。**
> `local/` 已列入 `.gitignore`，不會被推上去。

### 1. 建立試算表與後端

1. 開 [sheets.new](https://sheets.new) 建一份新的 Google 試算表，命名為「陶藝班值日生」。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把編輯器裡原本的 `function myFunction() {}` 全部刪掉，貼上 **`local/Code.gs`** 的完整內容，存檔（Ctrl/Cmd + S）。
4. 函式下拉選單選 **`setup`** → 按 **執行**。
   第一次會跳出授權：選你的 Google 帳號 →「進階」→「前往（不安全）」→ 允許。
   *（這個「不安全」提示是因為腳本沒經過 Google 審核，這是你自己的腳本，正常現象。）*
5. 回到試算表，6 張工作表都建好了，**排班表已經依設定產生 18 堂，並且把你 LINE 上已經排好的人填進去了**。

### 2. 填入班上資料

- **學員名單**：目前只有 LINE 上看得到的 8 位，請把其餘同學一列一位補上。`Email` 欄選填。
- **設定**：把「班長信箱」填成你的 email。其他預設值可以先不動。
- **特殊安排**：已預填 10/27 公民週與 12/29 期末聚餐。有其他停課日就加一列。

### 3. 開啟自動提醒

Apps Script 函式選 **`installTriggers`** → 執行。
系統會依「第一堂課日期」自動判斷上課是星期幾，把提醒排在**上課當天早上 07:00**、進度信排在**前一天晚上 20:00**。

### 4. 部署成 API

1. Apps Script 右上角 **部署 → 新增部署作業**。
2. 齒輪圖示選 **網頁應用程式**。
3. 兩個關鍵設定 —— **一定要這樣設，否則同學會打不開**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按部署，複製那串 **網頁應用程式網址**（`https://script.google.com/macros/s/AKfy.../exec`）。

### 5. 上線網頁

1. 編輯 [`docs/config.js`](docs/config.js)，把網址貼進去。
2. 推上 GitHub：
   ```bash
   cd /Users/chadkuo/pottery-duty
   gh repo create pottery-duty --public --source=. --remote=origin --push
   ```
3. GitHub repo → **Settings → Pages** → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 **`/docs`** → Save。
4. 一分鐘後就有網址：`https://<你的帳號>.github.io/pottery-duty/`
5. **把網址貼到 LINE 群組公告**，收工。

## 日常使用

### 同學

打開網址 → 上方選自己的名字（只需選一次，瀏覽器會記住）→ 點想值日那天的「＋ 我要值日」。

名單裡沒有你？選「✎ 名單裡沒有我，加入名單…」，輸入名字就會寫進學員名單，之後大家都選得到。

### 當天不能到 → 代班

1. 值日生在自己那天按 **「我不能到，找人代班」**（可留原因）。
2. 網頁最上方立刻出現橘色求救橫幅：*「9/22（二）吳雅婷 無法出席」*，全班都看得到。
3. 任何人按 **「我來代」** → 排班表上的名字直接換成代班人，次數自動轉移。
4. 原值日生若又能到了，按 **「我可以到了，取消徵求」** 即可撤回。

整個過程班長不用介入。誰代誰、什麼時候，都記在「代班需求」工作表。

> 沒人接手的話，那個人**仍然是值日生**（名字還掛在排班表上），只是大家都知道他在找人。
> 上課當天早上的提醒信也會標註「⚠ 徵求代班中，還沒有人接手」。

### 班長

試算表上方會多一個 **「值日生」選單**：

- **依設定重建排班表** — 改完設定後按這個（會先跳確認視窗，並自動備份）
- **清空所有值日生（重新排班）** — 讓全班從頭排一次
- **產生 LINE 公告文字** — 輸出成跟原本接龍一樣的格式，直接複製貼回群組
- **立即寄出今日提醒** / **立即寄出進度給班長** — 不等排程，馬上手動寄一次
- **重新建立自動提醒排程** — 上課星期改了之後按一下

排班全部確定後，把「設定」的 **開放報名** 改成 `FALSE`，網頁就變唯讀。
只想關代班功能的話改 **開放代班**。

## 改某一堂課（停課、補課、調日期）

網頁上顯示的每一行，例如：

```
10/27（二）第 9 堂・社大公民週      不用排值日生
```

`社大公民週` 來自「說明」欄，`不用排值日生` 來自「需排值日生」那個勾勾。
兩者都可以在試算表改，但**有兩個地方可以改，用途不一樣**：

| 改哪裡 | 什麼時候生效 | 重建排班表之後 |
| --- | --- | --- |
| **排班表** 工作表（直接改那一列） | **立刻**，同學重新整理網頁就看到 | **會被蓋掉** |
| **特殊安排** 工作表（加一列日期） | 下次重建排班表時 | **永久保留** |

### 臨時狀況 → 直接改「排班表」

這學期臨時停一次課、補課換到別天，直接在**排班表**那一列上改就好，不用重建、不用碰程式：

| 想做什麼 | 怎麼改 |
| --- | --- |
| 某天改成不用排值日生 | 把該列的 **需排值日生** 勾勾取消 |
| 加上說明文字 | 在該列的 **說明** 欄打字，例如 `颱風停課` |
| 補課調到別天 | 直接改該列的 **日期** 欄 |
| 換掉某位值日生 | 直接改該列的 **值日生 1/2/3** 欄 |
| 多加一堂課 | 在最後面加一列，填週次、日期，並勾選需排值日生 |

**取消勾選不會刪掉原本排的人。** 名字還留在儲存格裡，只是那一堂暫時不算值日生、也不計入次數。
把勾勾點回來，人和次數就都回來了。

### 每學期固定的 → 寫進「特殊安排」

公民週這種每學期都有、而且希望重建之後還在的，就在**特殊安排**加一列：

| 日期 | 說明 | 需排值日生 |
| --- | --- | --- |
| `2026-10-27` | 社大公民週 | ☐（不勾） |
| `2026-12-29` | 吃好料的時光 | ☐（不勾） |

重建排班表時，這些設定會蓋到對應的那一堂上。

> **一句話記法：** 這學期臨時的，改「排班表」；每學期都要的，寫「特殊安排」。
> 兩邊衝突時，重建之後以「特殊安排」為準。

## 重置：讓全班重新排一次

想把目前排好的人全部清掉、讓大家在網頁上從頭排（例如剛上線時想拋棄 LINE 接龍的舊結果），
用選單 **值日生 → 清空所有值日生（重新排班）**。

- **只清值日生欄位。** 日期、說明、需排值日生的勾選、學員名單、代班紀錄都保留
- 按下去會先跳確認視窗，列出將清掉幾個名額、哪幾堂、有誰
- 按 **取消** 什麼都不會發生
- 按 **確定** 前會自動備份成「排班表 備份 MMdd-HHmm」，按錯了複製貼回來就好
- 進行中的代班徵求會一併標記為失效
- 排班表本來就是空的時候，會直接告訴你不用清

### 手動版（不想用選單的話）

在**排班表**選取值日生那幾欄（`E2:G19`，看你有幾堂幾人）按 Delete 即可，效果一樣。
差別是沒有備份，而且要自己選對範圍 —— 選到 B 欄會把日期一起刪掉。

### 其他層級的重置

| 想清掉什麼 | 怎麼做 |
| --- | --- |
| 值日生（最常見） | 選單「清空所有值日生」 |
| 某一堂的某一個人 | 直接把排班表那一格刪掉 |
| 整份排班表重來（含日期） | 選單「依設定重建排班表」 |
| 學員名單 | 在「學員名單」直接刪掉那幾列 |
| 代班歷史、操作紀錄 | 在該工作表刪掉第 2 列以下（保留標題列） |
| 備份工作表 | 分頁上按右鍵 → 刪除 |

## 換學期：改三格，按一次

**同學看到的網頁上沒有任何「重建」按鈕。** 這些功能只出現在試算表的「值日生」選單裡，
只有拿得到試算表編輯權限的人（你和班長）才碰得到，同學連看都看不到。

### 步驟

1. **設定** 工作表，改橘色底那三格：
   | 設定項目 | 改成 |
   | --- | --- |
   | 學期名稱 | `2027 春季班` |
   | 第一堂課日期 | 新學期第一堂的日期，例如 `2027-02-16` |
   | 總堂數 | 例如 `18` |

   上課是星期幾**不用填**，系統會從第一堂課日期自己算出來。

2. **特殊安排** 工作表：把上學期的停課日刪掉，填新學期的（公民週、國定假日、期末聚餐…）。

3. **學員名單** 工作表：沒續報的同學整列刪掉，新同學可以先加、也可以讓他們自己在網頁加入。

4. 上方選單 **值日生 → 依設定重建排班表**。

5. **只有在上課星期改變時**（例如週二班改成週四班），再跑一次
   **值日生 → 重新建立自動提醒排程**，否則提醒信會寄錯天。

網址完全不用動，LINE 群組公告裡那條連結繼續用。

### 按下「重建」不會出事

按下去**不會立刻執行**。會先跳出一個視窗，把即將發生的事寫清楚再問你：

```
重建排班表

將依「設定」重新產生排班表：

　學期　2027 春季班
　課程　2027-02-16 起，每週二，共 18 堂
　最後一堂　2027-06-15
　每週值日生　3 人

日期相同的 0 堂，排班會原樣保留。

⚠ 以下 18 筆排班會被清空：
　2026-09-01（王小明、陳美玲、林志豪）不在新學期範圍內
　2026-09-08（王小明、張淑芬、黃俊傑）不在新學期範圍內
　…以及其他 16 筆

動手前會自動把目前的排班表另存一份備份，按錯了也救得回來。

確定要重建嗎？　　[ 確定 ]  [ 取消 ]
```

- 按 **取消** → 什麼都不會發生，連備份工作表都不會產生。
- 按 **確定** → 先自動把目前的排班表另存成 **「排班表 備份 0216-1030」**（月日-時分），再重建。
  萬一真的按錯，上學期的排班原封不動留在那張備份裡，複製貼回來就好。
  確認新排班沒問題後，那張備份可以自己刪掉；不刪也沒關係，它同時就是上學期的存檔。
- 設定填錯（例如日期打成「下週二」）→ 直接跳錯誤訊息，**完全不會動到排班表**。

### 重建時原有的排班會怎麼樣

規則只有一條：**日期一模一樣的才保留，其餘一律清空並列在確認視窗裡。**

| 你改了什麼 | 原有排班 |
| --- | --- |
| 總堂數 18 → 20 | 全部保留，後面多兩堂空的 |
| 總堂數 20 → 18 | 前 18 堂保留，被砍掉那兩堂的人列在警告裡 |
| 特殊安排新增一天「不排值日生」 | 那天原本排的人被清空，列在警告裡 |
| 每週人數 3 → 4 | 保留，每天多一個空位 |
| 每週人數 4 → 3 | 保留前 3 位，第 4 位列在警告裡 |
| 換學期（第一堂課日期整批改掉） | 全部清空 —— 這正是新學期要的 |

> 曾經試過「日期對不上時改以第幾堂對應」來救資料，但那樣換學期時會把上學期整份排班
> 默默複製到新學期，班長不一定看得出來。規則單純可預期，比聰明重要。

「代班需求」裡對不上的徵求會自動標成「已失效」。上學期的次數自然歸零，因為次數是從排班表算出來的。

## 設計上的取捨

**沒有登入機制。** 同學從下拉選單挑自己的名字就能報名 — 跟原本 LINE 接龍一樣，靠班上的互信。
好處是零摩擦，年長同學也會用；代價是理論上有人可以幫別人取消。
每一筆異動都寫進「操作紀錄」，真的出事查得到，也能手動改回來。若之後需要，再加密碼不難。

**代班採「先掛著、有人接才換」。** 徵求期間原值日生仍掛在排班表上，不會出現「今天沒有值日生」的空窗。
次數的轉移是排班表的自然結果（名字換掉，次數就跟著換），不需要另外維護一份計數。

**提醒走 Email 而不是 LINE。**
LINE Notify 已於 2025/3/31 終止服務。改用 LINE 官方帳號（Messaging API）的話，
免費方案訊息額度很低，而且**推播到群組是按群組人數計費**，57 人 × 每週一次會直接爆掉。
所以預設走 Gmail（Apps Script 每天 100 封免費額度，我們一週用不到 5 封）。

> 「設定」裡的 **代班通知全班** 預設是 `FALSE`。開成 `TRUE` 的話，每次有人徵求代班就會寄信給全班；
> 57 人一次就是 57 封，同一天發生兩次就會撞到 Gmail 的 100 封上限。建議維持 `FALSE`，
> 靠網頁上的求救橫幅 + 在 LINE 貼一次連結就好。

未來若想要 LINE 通知，唯一真正免費的做法是「機器人只回覆、不主動推播」：
把 bot 加進群組，有人輸入「值日生」它才回答（reply 訊息不計免費額度）。
這可以之後再加，不影響現在的架構。
